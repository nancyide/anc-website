Public dataset and software archives referenced by the ANC website, copied for migration on September 25, 2026.

Each archive was copied from the existing server and checked against a SHA-256 hash calculated on the source. Original URL paths, sizes, checksums, and target download URLs are recorded in `migration/download-manifest.json` in the repository. `SHA256SUMS` covers the archive assets by filename.

This release supplies downloads for https://nancyide.github.io/anc-website/. It is not a complete backup of the original server. Existing license and attribution requirements for each dataset/software package continue to apply.
