Corpus and annotation overview

CHART LEGEND

DOCUMENT NAME is the base name used for the primary data file and all of its associated standoff annotation files and headers

WORD COUNT is the number of words in the document

TYPE is spoken or written

GENRE indicates the genre of the data, drawn from the ANC controlled vocabulary for text categorization

SUB-CATEGORY provides an additional classification of the data, where one exists; these classifications reflect the MASC directory structure

ANNOTATIONS lists annotations for the document beyond the basic set, which includes logical structure (body, paragraph, headings, etc.); sentence boundaries; token and part of speech (ptbtok and fntok); token, part of speech, and lemma (penn); noun chunks; verb chunks; named entities (person, location, date, organization), and Penn Treebank Syntax. Other annotations are indicated in the chart below as follows:

FN = FrameNet
MPQA = Opinion Annotation (Pittsburgh)
CB= Committed Belief (CMU)
EV = Event (CMU)
PB = PropBank (PropBank annotations are currently available in their original format only)

Each text is viewable by clicking on its file name.
