tools

  • ANCTool : Convert ANC data and annotations to other formats, including in-line XML, CoNLL IOB format, word/POS for use with NLTK and other software
  • GATE Tools : Import and export ANC data and annotation into and out of the General Architecture for Text Engineering (GATE)
  • UIMA Tools : Import and export ANC data and annotations into and out of the Unstructured Information Management Architecture (UIMA)
  • GrAF API : Access and manipulate OANC and MASC annotations directly from Java programs
